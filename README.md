# 无限梦境 · Infinite Dream Preview

本仓库是「无限梦境」的提前测试版本，用于为[正式版](https://github.com/Designer-Awei/infinite-dream)探索新功能、尝试玩法改动并进行测试验证。新功能会先在预览版中试验，根据测试结果调整完善后，再考虑同步到正式版。预览版内容可能随测试发生变化。

像素风地牢肉鸽（元气骑士式闯关 + 荒野乱斗式地图与操作）。六位角色：大肥鱼、吉普缇、格洛克、克劳德、奶糖包、吉拉姆。
浏览器打开即玩，无需注册；手机横屏支持虚拟摇杆；2~4 人联机合作或竞技场 PVP。

- 操作：电脑 WASD 移动 · J 攻击（范围内自动吸附锁敌）· K 技能 · L 大招 · 空格闪避；手机左侧摇杆 + 右侧技能键（轻点自动瞄准，拖动手动瞄准）。
- 闯关：三张主线地图（数据草原 / 显存冰原 / 算力熔炉）与无尽回廊。一局 7 个房间：战斗 → 战斗 → 补给站 → 精英战 → 战斗 → 补给站 → 地图首领。清场开箱三选一技能卡，借用其他角色的弹幕与技能触发元素反应。
- 梦境裂隙：无尽模式挖宝后返回当前进度继续闯关，不会提前结算；所有战斗模式的裂隙窗口均可“放弃进入”，每次放弃在本局最终结算额外获得 200 晶石，无尽中可累计，进入裂隙不领取这项奖励。
- 无尽补给站：可抽技能卡全部达到上限后，抽卡机器对该角色直接消失，不再扣币或打开空选卡界面；空补给箱奖励自动跳过，传送门照常开放。合作按各自卡池判断。
- 梦境矿场：用铲子下潜挖矿，带回晶石、矿石、星砂；矿场装备升级、梦境工坊（最终减伤、SSR 兑换卡、角色梦核）、每日委托。
- 局外养成：晶石扭蛋（永久天赋，SSR 天赋装配到角色）、角色梦核、怪物图鉴，以及各地图稀有怪物掉落的梦境藏品。

## 无尽分阶段难度（预览版）

- 1–30层保留轻松开荒节奏，31–60层承接约35层成型的卡牌构筑，61层后加速提升，120层作为当前版本强构筑的挑战目标，不设硬性封顶。怪物生命/伤害用平滑阶段曲线；算力方块前40个保持完整收益，之后递减但持续有效，人物与宠物共用同一增伤。元素反应的额外楼层系数在35层停涨。主线和竞技场原数值不变。[公式、假设与实测](design/ENDLESS_STAGE_BALANCE.md)。
- 卡池抽空后，无尽战斗房清场直接开传送门，不再生成宝箱；合作队友仍有可选卡时保留奖励。补给站空卡池机器继续隐藏且不扣钱。
- 工坊兑换卡可兑换1级未满SSR或1积攒点；积攒点右侧预览沿用扭蛋机渐变背景，左条为当前值、右条循环增长+1，中间显示点数变化，不展示机器，预览不消耗资源；兑换按钮使用2px黑色轮廓线、无文字投影；音效/音乐开启显示绿色、关闭灰色；冰原与熔炉首页卡片去掉倍率文字，完整显示通关数，实际收益不变。

- 横屏短屏的角色卡顶部三行保留 4px 行距，通过内部留白分配保证普攻、小技能、大招的描述至少完整显示一行，保持现有字体、卡片外框和人物尺寸。
- 角色详情头像保留在左上角，右侧第一行为角色名与等级、经验，文字下沿对齐；第二行为不加「」的称号、元素和定位标签。两行间距 3px，头像与两行整体等高，字号保持原样，满级显示与星徽保留。

## 结算界面

- 横屏战斗、矿场结算统一为约 80% 可用屏高（最高 460px），恢复较紧凑的面板比例；人物略微放大，短屏高固定 110px、较高屏固定 150px，不因收获条数变化而缩小，右侧操作按钮固定在面板内。
- 左侧摘要最少一项、最多两项：没有额外收获时显示“本局晶石”；有多项时优先展示首通/解锁/纪录、新藏品、裂隙收获等。
- 超过两项时，第一项缩短，右侧放置同高同风格的“其余 N 项”按钮（无箭头），第二项保持整行；点击可在上拉浮窗中查看完整明细。
- 矿场左侧展示本次下潜角色、晶石和矿石/星砂收益（最多两条）；右侧集中展示统计、带出材料、委托与遗物。材料按价值降序排成两列，仅一种时占整行，四字材料名与数量保持同一行；包含全部 11 种材料时明细区可滚动，按钮不随内容滚出面板。空手结算保留明确提示，继续/再次下潜/返回矿场沿用原逻辑。
- 两种结算右下角、裂隙窗口的操作按钮和通知横条文字均使用单层 2px 黑色描边，不叠加文字阴影；结算按钮保持无按钮投影。“梦境矿场”收获行去掉镐子字符，与其他文字左对齐。

## 运行 / 部署

```sh
npm install                                # 安装依赖（含打包工具 esbuild）
cd web && python3 -m http.server 8000      # 开发：直接用 ES 模块运行，打开 http://localhost:8000
./tools/build.sh                           # 打包到 dist/ 和 docs/（静态站点，约 19MB）
python test/update-integrity.py --git-ref HEAD # 检查构建与已提交文件是否符合热更新清单
```

构建会先将发布文本统一为 LF 换行，再生成大小与校验值；docs 的 Git 换行规则保持一致，避免 Windows 构建的清单与线上文件不符。更新失败时保留原版本和本机存档；修复发布后重新启动应用可再次更新，无需卸载。可用 `python test/update-integrity.py --url https://designer-awei.github.io/infinite-dream-preview/` 核验全部线上资源。

GitHub Pages：仓库 Settings → Pages → Deploy from branch → `main` / `docs`。
联机走 PeerJS（WebRTC 点对点，免费公共信令）；也可以 `?peer=你的域名:端口` 指定自建 PeerServer。`?local` 用 BroadcastChannel 在同一浏览器双开调试。

## 目录

- `web/js`：游戏代码（`game.js` 模拟、`skills.js` 角色技能、`enemies.js` 敌人与首领、`render.js` 渲染、`net.js` 联机、`mine.js` 梦境矿场、`codex.js` 怪物图鉴与藏品、`ui.js` 界面、`data.js` 全部数值）
- `web/pixelfx`：[patch-gg/pixelfx](https://github.com/patch-gg/pixelfx)（MIT）特效库
- `art/`：角色、大厅动画与新怪物的源帧（PixelLab 生成）
- `tools/`：角色抠图像素化、角色 / 大厅 / 怪物动画打包、字体裁剪、打包脚本
- `test/`：Playwright 自动试玩（整局机器人、联机双开、手机触屏、矿场、界面核对、性能）
- `DESIGN.md`：元气骑士玩法拆解、框架选择、数值设计

素材：角色形象来自项目素材包 `ai-girls`，部分角色与怪物动画由 PixelLab 生成；字体 Cubic 11（OFL）。
