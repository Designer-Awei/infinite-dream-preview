# 无限梦境 · Infinite Dream Preview

本仓库是「无限梦境」的提前测试版本，用于为[正式版](https://github.com/Designer-Awei/infinite-dream)探索新功能、尝试玩法改动并进行测试验证。新功能会先在预览版中试验，根据测试结果调整完善后，再考虑同步到正式版。预览版内容可能随测试发生变化。

像素风地牢肉鸽（元气骑士式闯关 + 荒野乱斗式地图与操作）。六位角色：大肥鱼、吉普缇、格洛克、克劳德、奶糖包、吉拉姆。
浏览器打开即玩，无需注册；手机横屏支持虚拟摇杆；2~4 人联机合作或竞技场 PVP。

- 操作：电脑 WASD 移动 · J 攻击（范围内自动吸附锁敌）· K 技能 · L 大招 · 空格闪避；手机左侧摇杆 + 右侧技能键（轻点自动瞄准，拖动手动瞄准）。
- 闯关：三张主线地图（数据草原 / 显存冰原 / 算力熔炉）与无尽回廊。一局 7 个房间：战斗 → 战斗 → 补给站 → 精英战 → 战斗 → 补给站 → 地图首领。清场开箱三选一技能卡，借用其他角色的弹幕与技能触发元素反应。
- 诅咒：本局状态，最多 5 个、同种不重复，来源为血契商人的诅咒契、诅咒宝箱的诅咒结果（背上随机诅咒并选卡；5 个已满时不会开出诅咒）、老虎机三连骷髅（扣 1 生命并背上随机诅咒；已满时敌人生命 +10%）。种类：虚弱（伤害 -12%）、迟缓（移速 -10%）、易碎（护盾上限 -1，至少 1）、贫穷（金币获取 -35%）、敌意（之后生成的敌人生命 +15%）、沉重（闪避冷却 +40%）、失血（每进入新房间失去 1 生命，不致死）。背上时头顶紫字“诅咒·X”并有紫色符文圈；HUD 金币下方每个诅咒一个紫色小标签（骷髅图标 + 名字），点击弹出效果。解除：净化之火、赎罪契（头顶“解除·X”）。诅咒随冒险续玩存档保存。
- 背上诅咒时玩家脚下出现紫色符文圈：画在角色下层、跟随玩家，1.6 秒后消失（之前留在原地常驻并盖在访客上）。
  - 诅咒卡（仅在背负诅咒时进入卡池）：以痛为力（SR，每个诅咒伤害 +10%）、诅咒共鸣（SR，每个诅咒暴击率 +5%、护盾上限 +1，随诅咒增减）、血之馈赠（SR，背负诅咒时击杀 6% 概率回 1 生命、清空房间 +15 金币）、净化之火（R，最多 2 张，立刻解除最近的诅咒并回 2 生命）。图标为代码绘制的像素图标（滴血之刃、诅咒之眼、金缎血滴、白金火焰），HUD 诅咒标签用骷髅印记图标。
- 精英词缀：每个精英怪（非首领、非镜像分身）生成时随机一个词缀，血条上方写“精英·词缀”（词缀颜色）并带光效：迅捷（移速 +45%，身后速度线）、坚盾（额外 50% 生命的蓝色护盾条先扣，打破时“护盾破碎！”眩晕 1.2 秒，蓝色护罩）、分裂（死后裂成两只 18% 生命、缩小的同种分身，绿色重影）、爆裂（死后原地红色符文 0.8 秒后爆炸，半径 52 扣 1 点，橙色闪烁）、再生（2 秒没挨打每秒回 5% 生命，飘绿色十字）、霜环（半径 72 寒气圈，圈内玩家减速）。联机由主机掷词缀并同步。
- 完美闪避：闪避开始后 0.24 秒（闪避无敌时间）内被敌人的子弹、撞击或技能命中判定挡下即触发（地面熔岩、灼烧不算）：头顶“完美闪避！”、紫色闪光，闪避冷却清零、3 秒伤害 +50%、大招 +6%，2 秒冷却；单人另有 1.6 秒子弹时间——敌人行动、敌方子弹与敌方区域技能以 30% 速度运行（玩家、宠物、己方子弹不受影响），画面紫色调、边框脉动、从角色扩散一圈波纹，顶部显示“子弹时间”。结算附加行“完美闪避 N 次”。
- 按钮文字统一为单圈黑色描边（-webkit-text-stroke，大按钮 3px、小按钮 2px），不再用八向投影；灰色按钮为深色字无描边（深色底上的白字灰按钮另加描边）。
- 称号：16 个称号分冒险 / 矿场 / 宠物三类，达成条件后自动获得（主页与矿场主页打开时检查，新称号弹出“获得称号”面板：旋转光芒、称号牌与效果，“好的 / 去佩戴”）。入口：主页标题右侧的称号牌（佩戴中的称号，未佩戴时为“称号 已得/总数”），其右端（含小翼）与下方角色介绍框右边对齐。称号面板左侧整块为“局内预览”场景（参考宠物技能预览）：铺满的草地上当前所选角色待机，按自身像素的整数倍放大（约占预览高度一半，保持清晰），头顶与单人局内一致：血条（含护盾线）与其上方的称号牌，比例同局内；底部浮条写效果（未获得的写“未获得 · 效果”）。预览显示右侧点选的称号（打开时为佩戴中的那个，点任一行即可切换预览，不必先佩戴，选中行金色描边），右侧按标签列出该类称号（已获得在前、按稀有度排），每行固定高度，右侧开关：已获得未佩戴为“佩戴”、佩戴中为“卸下”，未获得的行留空并在进度条里写条件与进度。佩戴的称号写进 kit：局内角色头顶（名字上方）显示称号牌，联机时其他玩家可见；效果只在 PVE 闯关生效（竞技场只显示）。
  - 统一稀有度模板（HTML 与画布同一套）：普通（灰白）、稀有（蓝，呼吸光晕）、史诗（紫，扫光）、传说（金，六边形尖角牌 + 扫光 + 金色光晕）、流彩（粉，六边形尖角牌 + 扫光 + 色相循环）；六边形牌由黑环、框色、底色三层同形六边形叠成，尖角深度按字号缩放，任何尺寸描边一致；扫光只在牌框内的底色区域内移动（HTML 与局内画布都裁切）。新增称号只需在 titles.js 的 TITLES 加一行（名字、稀有度、分类、条件文字、进度函数、效果；可选 col/bg 覆盖颜色、still 关闭变色）。
  - 冒险：初入梦境（普通，完成 1 局，开局金币 +10）、百战幻影（稀有，击败 1000 敌人，伤害 +4%）、首领猎手（史诗，击败首领 30 次，对首领伤害 +10%）、元素指挥家（史诗，元素反应 2000 次，反应伤害 +15%）、幻影舞者（传说，完美闪避 100 次，闪避冷却 -20%、完美闪避判定 +0.1 秒）、回廊行者（传说，无尽 30 层，护盾上限 +1）、噩梦主宰（流彩，固定红色、不变色，噩梦契约 19 级通关，受到攻击时 15% 概率完全抵消并显示“免伤”）。
  - 矿场：见习矿工（普通，下潜 10 次，拾取范围 +15%）、深渊勘探者（稀有，最深 30 米，移速 +5%）、委托达人（史诗，完成每日委托 30 个，局内金币 +15%）、地心之王（传说，最深 80 米，受伤后无敌 +0.3 秒）。
  - 宠物：萌宠伙伴（普通，孵化 5 次，大招充能 +5%）、孵化专家（稀有，孵化 50 次，大招充能 +10%）、传说驯养师（史诗，获得 10 只传说及以上，暴击率 +5%）、驯兽大师（传说，图鉴全部 18 种，伤害 +10%、暴击率 +8%）、流彩之主（流彩，集齐全部种类的流彩，伤害 +8%；与噩梦主宰同为固定红色标签，不变色）。孵化次数、传说以上获得数、获得过流彩的种类记在宠物存档里（旧存档按仓库现有宠物补齐）；矿场记录完成委托数与累计击败数；冒险记录完美闪避累计次数。
- 每日梦境（V4）：主页模式轮播最右侧的卡（当天地图缩略图 + 当天角色头像，卡上不再放日历徽章；底部为短句“已打卡 · 连续 N 天 / 未打卡 · 连续 N 天 / 未打卡”，保证完整显示）；选中后大按钮显示“每日梦境”，点开每日面板。由本地日期（FNV-1a 哈希）决定当天的种子（同一路线与房间）、角色（六人之一，未解锁也能用）、地图（三张主线之一，不受解锁限制）、两条 1 级噩梦契约（合计不超过 4 点，所以不会同时出现凶猛与护盾停转）、一个梦境祝福（灵感涌现：开局三选一 SR 起卡 / 坚实梦体：开局生命上限 +2 / 梦境盘缠：开局 120 金币 / 蓄势待发：开局大招充满）。面板左侧为当天地图上的角色立绘，右侧三行：契约、祝福、纪录（挑战次数、最远层数、是否通关），下方 7 天打卡日历（已领的打勾变暗、今天金框发光）与“开始挑战 / 再次挑战”。一局结束（胜负都算）且是当天的梦：首次结束即打卡，连续天数 +1（昨天打过卡则续，否则重置为 1），发连续第 N 天（7 天循环）的奖励：200 晶石、淬灵露×1、300 晶石、UR 宠物蛋×1、淬灵露×2、500 晶石、流彩晶×1；当天第一次通关另 +300 晶石。结算页显示“每日打卡 · 连续 N 天 · 奖励”和“每日通关”行，副标题加“每日梦境 · ”，“再来一局”重开当天的梦。每日梦境不计入地图通关次数 / 解锁，也不享受噩梦契约晶石加成与里程碑；跨过零点才结束的局只记录不打卡。存档 daily.{last, streak, days} 只保留最近 40 天。冒险续玩会保留每日标记。
- 每日梦境提醒：当天未打卡时，主页通知条第一条就是“每日梦境未打卡”（月亮日历徽章、紫色边框，任何屏幕都只占一行，右侧“去挑战 ▶”），停留 12 秒，之后与其他通知（孵蛋提醒 / 下一个目标 / 小知识，每条 6 秒）交替轮换、每轮之间都插回每日提醒；点击后模式轮播滑到最右侧的每日梦境卡并选中。当天打卡后通知条不再出现每日梦境。模式卡不显示红点，靠卡底“今日未打卡”文字提示；点通知条跳转后轮播会完整吸附到最右侧卡片。
- 冒险续玩（类似元气骑士）：单人 PVE（主线与无尽，不含联机、竞技场、宠物试炼）从第 2 层起每进入一个房间自动存一次进度（层数、航线、技能卡与属性、生命护盾、金币、方块、大招、统计、诅咒等，存在独立的本地键里）。直接关掉游戏或在暂停菜单点“保存退出”（暂停第二排变为 放弃本局 / 保存退出 / 继续 三格）都会保留；回到主页时“开始冒险”变为蓝色“继续冒险”，点击弹出“继续冒险”面板（地图与层数、角色、生命、金币、技能卡数，提示从这一层开头继续），可“继续”或“放弃”（放弃不结算，按钮恢复“开始冒险”）。通关、失败或放弃本局时清除。
- 选卡界面（技能卡与矿场遗物）：卡牌下方不显示数字角标，底部提示统一为“点击卡牌选择”（电脑上 1/2/3 键仍可选）。只有游戏用到的按键（字母、数字、方向、空格、Shift、Esc、回车）才会把界面切到键盘模式，手机的音量键、返回键等不再误切出键盘提示。
- 暂停面板的构筑：每种技能卡一个 30px 小图标（稀有度色边框，多张右下角数字），按 UR → N、张数从多到少排序，标题写“N 种 · M 张”；点图标在下方一行显示名字与效果。无尽长构筑也能一屏放下，不需要上下滑动。
- 热更新：对局中（闯关、矿场、联机房间）发现新版本只在后台静默下载，不弹窗、不重启，下载完提示“新版本已下载，下次启动时更新”，下次启动在主页切换；在主页时照常显示进度并重启。变更文件依次从 GitHub Pages、jsDelivr、GitHub 仓库原始文件下载，校验不一致或失败会隔几秒再试，共 3 轮；仍失败则面板改为“更新失败”，写明原因（服务器还在同步新版本 / 网络连接失败）和文件名，并提供“稍后”“重试”。
- 梦境裂隙：单人击败首领后 15% 概率出现。无尽模式挖宝后返回当前进度继续闯关，不会提前结算；所有战斗模式的裂隙窗口均可“放弃进入”，每次放弃在本局最终结算额外获得 400 晶石，并有 35% 概率再得 1 颗宠物蛋（与首领蛋分开计，不受一局 3 颗上限限制），无尽中可累计，进入裂隙不领取这项奖励；结算“放弃裂隙”一行写出次数、晶石和蛋数。
- 首领池：数据草原每局按种子从“幻觉之眼 / 根须之心”中选一位，显存冰原从“冰封史莱姆王 / 霜镜女巫”中选一位，算力熔炉从“过热核心 / 熔岩巨蠕”中选一位；无尽回廊每 10 层的首领按种子错位轮换全部首领（含雷霆审判者与食梦兽）；每日梦境的终点首领固定为食梦兽。
- 根须之心（数据草原，pixelfx 代码绘制的 144×128 待机循环：树根抓地、树皮球茎的裂缝随心跳发光、两侧荆棘藤摆动、鹿角状枝冠）：扎根不动、不受击退。根刺突袭（沿警示线从心脏向每名玩家裂开，0.75 秒后尖刺依次破土；二阶段起每人三条扇形）；孢子荚（落在玩家周围爆开，部分发芽成孢子节点）；二阶段起荆棘囚笼（荆棘圈围住一名玩家后 1.8 秒收拢，圈上与收拢后圈内受伤并减速，闪避穿出）；三阶段起藤鞭横扫（0.6 秒红色预警后两条荆棘藤绕心脏扫一圈）。每次换阶段缩进树皮 2.5 秒只受 20% 伤害并召唤藤蔓蛇与孢子节点。素材源码 tools/bossfx/root-heart.js，tools/render_bosses.mjs 渲染进 critters 图集。
- 霜镜女巫（显存冰原，pixelfx 代码绘制 128×136 待机循环：漂浮兜帽法袍、冰刺王冠、发光双眼、喉部宝石、两面绕身旋转的六角冰镜，袍摆结霜碎落）：在房间里漂移。镜像分身（闪身消失，与 2/3 个冰镜分身在房间四处同时出现；分身外形、首领红圈完全相同但没有影子、没有血条，一击即碎并偶尔放慢速冰片，9 秒后自行消散；换阶段必定施放）；冰枪齐射（3/5 条预警线 0.6 秒后高速冰枪，命中减速）；霜环（自身向外扩散的霜冻环，站在环上受伤减速，闪避穿过）；三阶段起冰锥坠落（玩家脚下与周围预警圈 0.85 秒后落冰锥）。

- 宠物蛋三种，品质下限不同、上限一致：宠物蛋（奶白蓝点）、UR 宠物蛋（蓝壳白点，稀有及以上）、HUR 宠物蛋（紫壳金点，史诗及以上）。蛋为上窄下宽的像素蛋形（左上高光、右下阴影），三种蛋与孵化裂纹共用造型。
- 蛋的来源：首领（每个 1 颗，每局最多 3 颗）、矿场安全撤离且有挖掘或战斗时 35%（结算显示“挖到一颗宠物蛋！”）、积攒兑换、图鉴收集奖励。
- 孵化槽：顶部 3 个（空槽写“孵化槽”）。点蛋弹出“放入槽位”（实时倒计时：宠物蛋 3 分钟、UR 5 分钟、HUR 8 分钟，离线照常计时；槽满不可选）或“直接孵化”（星砂 = 分钟数 × 4，即 12 / 20 / 32）。槽内只显示蛋、倒计时和进度条，到点发光摇晃，点击揭晓。
- 孵化揭晓：蛋摇晃、三次裂开、宠物现身，背后全屏旋转射线（每次随机 9~12 道宽窄、间距不一的光束；品质色，品质越高越亮越快，流彩每道一种颜色），异色、流彩有专门提示，同时显示评分；揭晓 0.5 秒后点任意处返回。
- 仓库是全屏页，左上“◀ 返回”，顶栏有图鉴图标与道具、经验池、星砂、流彩概率（蛋的数量看右侧蛋卡片，顶栏不重复显示）。右侧格子先列各种蛋（数量，UR / HUR 标“稀有 / 史诗”），再列宠物（上锁最前，其次出战、异色、阶段、品质），卡片有阶段、品质色条、上锁与出战标记，异色金色流光、流彩彩色流光。没有宠物时左侧只显示蛋和一句提示。
- 左侧选中宠物：预览区按真实比例显示（同种三形态共用缩放，终极撑满可见区域，约 1 : 1.5 : 2.4，同一地面线，动作可超出边缘），左上角上锁按钮，右上角评分，点击预览进入详情（技能说明与演示；详情里各形态上下居中、投影在各自脚下）。下方名字、异色与品质标签、词条（数值、范围、位置条）、经验条（未满时右侧有注入加号）。按钮：出战 / 休息、淬炼（持有道具时）、融合，放生在最右。
- 进化：只需经验。局内达到 300 / 1200 当场进化（光柱、横幅“宠物进化！”，携带加成随阶段提高）；注入经验达到时也立即进化。携带宠物本局拿不下的经验（已满或中途满）计入经验池，结算“本局收获”显示“经验池 +N（宠物经验溢出）”。
- 注入经验：经验条右侧圆形加号（20px，与 18px 经验条垂直居中）。第一次点亮起黄色光圈并提示，之后每点一次从经验池注入 300（经验池不足或接近上限时按剩余），幼年到终极共 4 次；换选宠物后需重新点亮；经验池为空时变灰，满经验时隐藏。
- 评分 =（成长分 + 词条分）× 品质系数 × 异色系数，取整。成长分 幼年 200、成长 400、终极 600，阶段内按经验连续增长；词条分每条 500 × 数值 / 顶值；品质系数 普通 1.0 / 优秀 1.05 / 稀有 1.1 / 史诗 1.15 / 传说 1.25 / 流彩 1.4；异色 ×1.05（流彩换色不另算）。参考：普通终极约 850、优秀约 1000、稀有约 1200、史诗约 1450、传说约 1750，完美满词条传说终极 2000（异色 2100）；流彩终极满值 2940，淬到 150% 为 3990。显示为无底框文字，数字固定四位宽右对齐、品质色（流彩循环变色），提升时滚动上涨并飘出 +N。
- 融合：选中宠物点“融合”即为主宠，再在格子里点另一只作为副宠（不限种族；上锁、出战中的变暗），确认面板标出主宠 / 副宠并写明种族、品质（含升阶）、异色、流彩概率。结果为 0 经验幼年体：种族 70% 随主宠、30% 随副宠（同种必为该种）；品质取两者较高，同品质且为普通 / 优秀 / 稀有时 20% 再升一阶；词条在结果品质范围内随机两次取较好一组；异色按双亲异色只数 0 / 1 / 2 为 20% / 50% / 100%，颜色在结果种族的异色池随机；任一只为流彩则保留流彩，否则按与孵化共用的流彩保底概率。例：异色普通（主）+ 原色传说（副）→ 传说，50% 异色，70% 主宠种族。
- 放生：未上锁、未出战的宠物可放生；点一次按钮变为“确定”（宽度不变），再点放生。返还经验池 = 品质基础值（普通 100、优秀 200、稀有 300、史诗 400、传说 600、流彩 1000）+ 累计经验 × 50%，例如 300 经验的稀有成长 450、满经验传说终极 1200。
- 淬灵露（UR）：给传说及以下宠物随机一条未满词条 +2~5%，不超过品质上限；流彩晶（HUR）：仅流彩宠物可用，+2~5%，最高到原上限的 150%。
- 图鉴：仿怪物图鉴的弹窗（右上角关闭），左列 全部图鉴 / 赤焰火龙 / 霆尾灵狐 / 霜羽冰凰 / 收集奖励，默认全部；卡片为静态终极形态图（异色按配色重绘，未收集为剪影，原色与剪影同尺寸），底部说明获得方式；放生、融合后记录保留。
- 图鉴收集奖励（可领取时图鉴按钮与页签有红点）：收集 3 种 宠物蛋、6 种 淬灵露、9 种 UR 宠物蛋、12 种 经验池 +600、15 种 HUR 宠物蛋、18 种（全收集）流彩晶（旧存档领过 19 种奖励的记作已领）。
- 积攒兑换（扭蛋机“积攒”）：单页列表，面板高度不超过屏幕，列表在面板内上下滑动。依次为 UR 宠物蛋 2 点、HUR 宠物蛋 5 点、淬灵露 2 点、流彩晶 5 点，以及兑换专属称号（称号面板“兑换”页）梦境收藏家（传说，20 点，拾取范围 +20%、局内金币 +15%）、积攒之王（最高品质，50 点，伤害 +8%、暴击率 +5%），已拥有的显示“已拥有”并禁用。积攒条刻度 5 / 20 / 50（白色）。所有兑换按钮固定 128px 宽，积攒点数位数不再影响宽度；兑换按钮无下投影。曾短暂上架的幸运积攒者（3 点）已下架，买过的存档自动退还 3 点。
- 最高品质称号（噩梦主宰、流彩之主、积攒之王）统一为固定红色标签（#ff4a4a 边框 / #3a0a12 底），任何地方都不再循环换色。

## 结算界面

- 横屏战斗、矿场结算统一为约 80% 可用屏高（最高 460px），两种结算共用布局：左侧标题与右侧第一栏顶部对齐，标题下小字行与标题、角色各有间距；角色在左栏水平居中（手机约 140px 高），脚底与本局晶石数一行齐平，晶石数在左栏右侧右对齐；左下收获行与右侧按钮底边对齐，按钮固定在面板内。
- 左侧摘要最少一项、最多两项：没有额外收获时显示“本局晶石”；有多项时优先展示首通/解锁/纪录、新藏品、裂隙收获等。

- 矿场左侧展示本次下潜角色、晶石和矿石/星砂收益（最多两条）；右侧集中展示统计、带出材料、委托与遗物。材料按价值降序排成两列，仅一种时占整行，四字材料名与数量保持同一行；包含全部 11 种材料时明细区可滚动，按钮不随内容滚出面板。空手结算保留明确提示，继续/再次下潜/返回矿场沿用原逻辑。
- 两种结算右下角、裂隙窗口的操作按钮和通知横条文字均使用单层 2px 黑色描边，不叠加文字阴影；结算按钮保持无按钮投影。“梦境矿场”收获行去掉镐子字符，与其他文字左对齐。

## 运行 / 部署

```sh
npm install                                # 安装依赖（含打包工具 esbuild）
cd web && python3 -m http.server 8000      # 开发：直接用 ES 模块运行，打开 http://localhost:8000
./tools/build.sh                           # 打包到 dist/ 和 docs/（静态站点，约 19MB）
python test/update-integrity.py --git-ref HEAD # 检查构建与已提交文件是否符合热更新清单
```

构建会先将发布文本统一为 LF 换行，再生成大小与校验值；docs 的 Git 换行规则保持一致，避免 Windows 构建的清单与线上文件不符。更新失败时保留原版本和本机存档；修复发布后重新启动应用可再次更新，无需卸载。可用 `python test/update-integrity.py --url https://designer-awei.github.io/infinite-dream-preview/` 核验全部线上资源。

GitHub Pages：仓库 Settings → Pages → Deploy from branch → `main` / `docs`。
联机走 PeerJS（WebRTC 点对点，免费公共信令）；也可以 `?peer=你的域名:端口` 指定自建 PeerServer。`?local` 用 BroadcastChannel 在同一浏览器双开调试。
